## Installation K6 Windows

- winget install k6 --source winget

## Installation K6 Other OS

- https://grafana.com/docs/k6/latest/set-up/install-k6/

## Installation Project

- npm install
- k6 --version

## Make New K6 Project

- k6 new src/folder-path/file-name.js

## Running K6 Project

- k6 run src/folder-path/file-name.js

## Running K6 Project with Web Dashboard

- K6_WEB_DASHBOARD=true k6 run src/folder-path/file-name.js
